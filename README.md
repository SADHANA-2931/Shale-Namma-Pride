# Shale-Namma Pride

## Overview

Shale-Namma Pride is a child-friendly Android application developed to improve transparency and communication between government schools and parents. The app helps schools showcase daily activities, facilities, student achievements, meal updates, and receive parent feedback digitally.

This project was developed as part of the **Android App Development using GenAI Internship Project**.

---

# Problem Statement

Many parents in rural areas are unaware of the facilities and improvements available in government schools. Due to this lack of awareness, parents often prefer private schools over nearby government schools.

Shale-Namma Pride addresses this issue by creating a digital platform where schools can regularly share updates and build community trust.

# User Flow

1. User opens app
2. Splash screen appears
3. User logs in or signs up
4. Dashboard opens
5. User can:

   * View meal updates
   * Check student achievements
   * Browse gallery
   * Read latest updates
   * Submit feedback
   * View profile
